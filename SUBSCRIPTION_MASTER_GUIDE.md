## 2. Database Setup (Supabase)
Ensure the following tables exist in your Supabase project.

### A. Run SQL Scripts
Go to the **SQL Editor** in your Supabase Dashboard and run these scripts (found in your `database/` folder):

1.  **User Profiles**:
    (If not already created)
    ```sql
    create table if not exists public.user_profiles (
      id uuid references auth.users(id) on delete cascade primary key,
      email text,
      full_name text,
      avatar_url text,
      role text default 'user',
      subscription_plan text,
      subscription_status text default 'inactive',
      created_at timestamp with time zone default timezone('utc'::text, now()) not null,
      updated_at timestamp with time zone default timezone('utc'::text, now()) not null
    );
    alter table public.user_profiles enable row level security;
    ```

2.  **User Subscriptions**:
    ```sql
    create table if not exists public.user_subscriptions (
       id bigint generated by default as identity primary key,
       user_id uuid references auth.users(id) on delete cascade not null unique,
       plan_type text not null,
       status text not null, -- 'active', 'cancelled', 'expired'
       purchase_date timestamp with time zone default timezone('utc'::text, now()) not null,
       expires_at timestamp with time zone,
       receipt text,
       created_at timestamp with time zone default timezone('utc'::text, now()) not null,
       updated_at timestamp with time zone default timezone('utc'::text, now()) not null
    );
    alter table public.user_subscriptions enable row level security;
    create policy "Users can view own subscription" on public.user_subscriptions for select using (auth.uid() = user_id);
    create policy "Users can update own subscription" on public.user_subscriptions for update using (auth.uid() = user_id);
    create policy "Users can insert own subscription" on public.user_subscriptions for insert with check (auth.uid() = user_id);
    ```

## 3. Google Play Console Setup (Essential)
This is the most critical part. The code refers to specific **Product IDs** that MUST match exactly in Google Play.

1.  **Create Developer Account**: [play.google.com/console](https://play.google.com/console)
2.  **Monetization Setup**: Go to **Setup** > **Payment profile** and create a merchant account.
3.  **Create Subscriptions**:
    Go to **Monetize** > **Products** > **Subscriptions**. Create the following:

    | Plan | Product ID | Base Plan ID | Price (GBP) |
    | :--- | :--- | :--- | :--- |
    | **Light** | `light_monthly` | `light-monthly-base` | £6.99 |
    | **Gold** | `gold_monthly` | `gold-monthly-base` | £19.99 |
    | **Business** | `business_monthly` | `business-monthly-base` | £39.99 |

4.  **Upload Build**:
    You MUST upload a signed AAB/APK with the `com.android.vending.BILLING` permission (included by the plugin) to an **Internal Testing** track.
    - Run: `npm run build && npx cap sync`
    - Open Android Studio: `npx cap open android`
    - Build > Generate Signed Bundle/APK.

5.  **Testers**:
    - Add your email to the **Testers** list in the Internal Testing track.
    - **CRITICAL**: Go to **Setup** > **License Testing** in the Console main menu and add your email there too. This is what allows you to use the "Test Card" free of charge.

## 4. Google Cloud Setup (Recommended)
You asked what needs to be done on Google Cloud.

**Why is this needed?**
For basic client-side implementations (like yours), it handles the API calls. For advanced security (server-side receipt validation), it provides the Service Account credentials.

**Steps:**
1.  **Google Cloud Project**:
    - Go to [console.cloud.google.com](https://console.cloud.google.com/).
    - Create a new project (e.g., "MigrantHub-Android").
2.  **Link to Google Play**:
    - Go back to **Google Play Console**.
    - Go to **Setup** > **API Access**.
    - Click **Link** to link your Google Play account to the Google Cloud Project you just created.
3.  **Enable API**:
    - In Google Cloud Console, search for **"Google Play Android Developer API"**.
    - Click **Enable**.
4.  *(Optional for current setup, required for Server-Side Validation)*:
    - Create **Service Account** in Google Cloud (IAM & Admin > Service Accounts).
    - Grant it access to the Google Play Console (Users & Permissions > Invite user > Email of service account).

*Note: The current codebase uses client-side logic (`cordova-plugin-purchase` local validation and direct Supabase updates). This setup is sufficient for an MVP. For high-security production apps, you would move `saveSubscriptionToDatabase` logic to a Supabase Edge Function using the Service Account from step 4.*
